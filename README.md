 💰 Finance Manager

Sistema de gerenciamento financeiro desenvolvido em Python com FastAPI para controle de receitas e despesas.

---

## 📌 Sobre o Projeto

O *Finance Manager* é uma API backend criada para registrar e organizar transações financeiras de forma simples e estruturada.

Este projeto foi desenvolvido com foco em:

- Organização em camadas (models e services)
- Estruturação de API REST
- Boas práticas de código
- Versionamento com Git
- Construção de portfólio para estágio em tecnologia

---

## 🚀 Tecnologias Utilizadas

- Python 3
- FastAPI
- Uvicorn
- Git
- GitHub

## 🔧 Como Executar o Projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/carolinaog-dev/finance-manager.git

2️⃣ Acessar a pasta
cd finance-manager

3️⃣ Instalar dependências
pip install fastapi uvicorn

4️⃣ Executar a aplicação
uvicorn main:app --reload

A aplicação estará disponível em:
http://127.0.0.1:8000

Documentação automática da API:
http://127.0.0.1:8000/docs

📌 Funcionalidades

✔️ Criar transações
✔️ Listar transações
✔️ Separação por tipo (receita / despesa)
✔️ Estrutura organizada por camadas
